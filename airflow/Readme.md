# Airflow

## Exemplos de schedule

| Schedule       | Executa               |
|---|---|
| `*/1 * * * *`  | A cada **1 minuto**   |
| `*/5 * * * *`  | A cada **5 minutos**  |
| `*/10 * * * *` | A cada **10 minutos** |
| `*/15 * * * *` | A cada **15 minutos** |
| `*/30 * * * *` | A cada **30 minutos** |
| `0 * * * *`    | A cada **1 hora**     |
| `0 */2 * * *`  | A cada **2 horas**    |
| `0 0 * * *`    | Todo dia à **00:00**  |
